Git Cheat Sheet

Git 2.x Daily Use Developer
⚙️Setup & Init
$ git --versionCheck Git version
$ git config --global user.name "Name"Set your name
$ git config --global user.email "email"Set your email
$ git config --global init.defaultBranch mainDefault to main
$ git config --listView all config
$ git initInit new repo
$ git clone <url>Clone remote repo
$ git clone <url> folderClone into folder
Run config once after installing Git. Email must match your GitHub account.
📸Core — Daily Commands
$ git statusWhat changed?
$ git add .Stage all files
$ git add <file>Stage one file
$ git add -p <file>Stage chunks interactively
$ git commit -m "msg"Commit staged files
$ git commit -am "msg"Stage tracked + commit
$ git diffUnstaged changes
$ git diff --stagedStaged changes
$ git diff main..featureDiff between branches
feat: · fix: · refactor: · style: · docs: · chore:
🌿Branching
$ git branchList local branches
$ git branch -aList all + remote
$ git checkout -b feature/xCreate + switch branch
$ git switch -c feature/xCreate + switch (modern)
$ git switch mainSwitch branch
$ git checkout mainSwitch branch (classic)
$ git branch -m new-nameRename current branch
$ git branch -d feature/xDelete merged branch
$ git branch -D feature/xForce delete branch
Name: feature/ fix/ refactor/ release/ hotfix/
☁️Remote & GitHub
$ git remote -vList remotes
$ git remote add origin <url>Link to GitHub
$ git remote set-url origin <url>Change remote URL
$ git push -u origin mainFirst push + set upstream
$ git pushPush current branch
$ git push origin feature/xPush specific branch
$ git pullFetch + merge
$ git pull --rebasePull + rebase
$ git fetchDownload (no merge)
$ git push origin --delete feature/xDelete remote branch
$ git push --force-with-leaseSafe force push
↩️Undo & Fix
$ git restore <file>Discard file changes
$ git restore --staged <file>Unstage a file
$ git restore .Discard ALL changes
$ git commit --amend -m "msg"Fix last commit msg
$ git commit --amend --no-editAdd to last commit
$ git reset HEAD~1Undo commit, keep changes
$ git reset --soft HEAD~1Undo, changes stay staged
$ git reset --hard HEAD~1Undo + delete changes ⚠️
$ git revert <hash>Safe undo (new commit)
$ git clean -fdDelete untracked files ⚠️
Use revert for pushed commits. Never --hard without being sure.
📦Stash
$ git stashSave dirty state
$ git stash push -m "wip login"Stash with label
$ git stash -uInclude untracked files
$ git stash listList all stashes
$ git stash popRestore + remove stash
$ git stash applyRestore, keep stash
$ git stash apply stash@{2}Apply specific stash
$ git stash dropDelete top stash
$ git stash clearDelete all stashes
Use stash when switching branches with unfinished work.
🔀Merge & Rebase
$ git merge feature/xMerge into current
$ git merge --no-ff feature/xAlways create merge commit
$ git merge --squash feature/xSquash all into one commit
$ git merge --abortCancel merge
$ git rebase mainReplay commits on main
$ git rebase -i HEAD~3Interactive rebase (3 commits)
$ git rebase --continueContinue after conflict
$ git rebase --abortCancel rebase
$ git cherry-pick <hash>Copy single commit
Never rebase commits already pushed to shared branches.
🔍Log & Inspect
$ git logFull commit history
$ git log --onelineCompact history
$ git log --oneline --graph --allVisual branch graph
$ git log -5Last 5 commits
$ git log --author="Name"Filter by author
$ git log --since="2 weeks ago"Filter by date
$ git log -p <file>File change history
$ git show <hash>Show commit details
$ git blame <file>Who wrote each line
$ git shortlog -snCommits per author
🏷️Tags & Releases
$ git tagList all tags
$ git tag v1.0.0Create lightweight tag
$ git tag -a v1.0.0 -m "msg"Annotated tag
$ git tag -a v1.0.0 <hash>Tag old commit
$ git push --tagsPush all tags
$ git push origin v1.0.0Push one tag
$ git tag -d v1.0.0Delete local tag
$ git push origin --delete v1.0.0Delete remote tag
$ git checkout v1.0.0Go to tagged version
Tag = snapshot of a release. Use semver: v1.0.0
⚡Advanced
$ git reflogHistory of HEAD (recovery)
$ git bisect startStart binary bug search
$ git bisect good / badMark commit good or bad
$ git submodule add <url>Add submodule
$ git submodule update --initInit submodules
$ git archive --format=zip HEADExport repo as zip
$ git grep "text"Search in tracked files
$ git gcCleanup / optimize repo
$ git worktree add <path> <branch>Work on two branches
$ git notes add -m "note" <hash>Attach note to commit
✂️Aliases — Type Less
$ git config --global alias.st statusgit st
$ git config --global alias.co checkoutgit co
$ git config --global alias.br branchgit br
$ git config --global alias.sw switchgit sw
$ git config --global alias.cm "commit -m"git cm "msg"
$ git config --global alias.ac "commit -am"git ac "msg"
$ git config --global alias.lg "log --oneline --graph --all"git lg
$ git config --global alias.undo "reset HEAD~1"git undo
$ git config --global alias.unstage "restore --staged"git unstage
$ git config --global alias.last "log -1 HEAD"git last
🔑SSH & GitHub Auth
$ ssh-keygen -t ed25519 -C "email"Generate SSH key
$ cat ~/.ssh/id_ed25519.pubCopy public key
$ ssh -T git@github.comTest GitHub connection
$ git remote set-url origin git@github.com:u/r.gitSwitch to SSH
$ git remote add upstream <url>Add upstream (fork)
$ git fetch upstreamGet upstream changes
$ git merge upstream/mainSync fork with original
$ git push --tagsPush release tags
$ git config --global credential.helper storeSave HTTPS credentials
Add public key at: GitHub → Settings → SSH keys
⚡ Common Workflows
🚀 New Feature
1$ git checkout main && git pull
2$ git checkout -b feature/x
3... write code ...
4$ git add . && git commit -m "feat: ..."
5$ git push -u origin feature/x
6Open Pull Request on GitHub
7Review → Approve → Merge
8$ git checkout main && git pull
9$ git branch -d feature/x
🔥 Hotfix on Production
1$ git checkout main && git pull
2$ git checkout -b hotfix/crash-fix
3... fix the bug ...
4$ git commit -am "fix: resolve crash"
5$ git checkout main
6$ git merge hotfix/crash-fix
7$ git push && git tag -a v1.0.1
8$ git push --tags
9$ git branch -d hotfix/crash-fix
🔄 Sync with Teammate
1$ git stash— save your WIP
2$ git checkout main
3$ git pull— get updates
4$ git checkout feature/x
5$ git merge main— bring in updates
6$ git stash pop— restore WIP
7Resolve conflicts if any
8$ git add . && git commit
9$ git push
😱 Undo Pushed Commit
1$ git log --oneline— find hash
2$ git revert <hash>— creates undo commit
3$ git push— push the revert
⚠️ NEVER git reset --hard on shared branches
🗜️ Squash Before PR
1$ git log --oneline— count commits
2$ git rebase -i HEAD~4— last 4 commits
3Change 'pick' to 's' to squash
4Save, write combined message
5$ git push --force-with-lease
🆕 First Repo to GitHub
1$ git init
2$ git add . && git commit -m "init"
3Create empty repo on GitHub.com
4$ git remote add origin <url>
5$ git push -u origin main
